# ECG VAE Project

Variational Autoencoder for 12-lead ECG signal processing and prediction.

## Overview

This repository implements a VAE-based model for:
- ECG reconstruction (1-lead and 12-lead)
- Cardiac condition prediction (LVF, MI, etc.)
- Adversarial learning with contrastive debiasing

## Usage

### Running the main training pipeline (12-lead)

```bash
python main_12.py --save True --version v_last --batch_size 300 --num_epochs 500
```

Or import and use the Trainer_12 class:

```python
from utils.helper_train2 import Trainer_12
from utils.helper_load import generate_12_loader

generate_12_loader(cv=0, batch_size=1000, labels=['lvf'], binary=False)
trainer = Trainer_12(version='v1', batch_size=300, components=600,
                     beta_ls=0.0, beta_nls=0.0001, gamma=3, pred=1,
                     patience=15, lr=0.0001, labels=['lvf'], leads12=1,
                     binary=False)
trainer.train_12(num_epochs=500)
```

### Command Line Arguments (main_12.py)

- `--save`: Save model checkpoint (default: True)
- `--version`: Version string for logging and model naming
- `--batch_size`: Training batch size (default: 300)
- `--num_epochs`: Maximum epochs before early stopping (default: 500)

## ECG Preprocessing

The project includes preprocessing scripts in the `preprocessing/` directory:

| File | Description |
|------|-------------|
| ecg12_preprocess.py | Unified QRS detection and beat extraction pipeline |
| fill_ecg.py | Load processed ECGs into mortality dataset |
| get_hb.py | Extract heart beats from raw signals |

## Data Format

### Input Data
- ECG signals: numpy arrays of shape `(12, 400)` or `(1, 400)`
- Labels: LVF classification (ordinal), binary MI detection, etc.

### Output Files (generated by scripts)
- `models/`: Saved model checkpoints (.pt files)
- `data/*.p` and `data/*.pt`: Preprocessed data loaders

## Model Architecture

### VAE Components
- **Encoder**: Convolutional or Linear stacked VAE with separation into:
  - Label-shared latent dimensions (predictive)
  - Non-label-shared latent dimensions (disentangled)
- **Decoder**: Symmetric reconstruction network

### Training Loss (for Trainer_12)
- Reconstruction loss (MSE) for ECG signals
- KL divergence (beta-VAE formulation) with separate weights for label/shared dimensions
- Adversarial contrastive loss for debiasing using MLP discriminator
